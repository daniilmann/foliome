# Foliome 1.0.1

This first local release includes a trusted kernel for preparation sessions and controlled page reads, filtered text and PNG snapshots, an owner interface, an executor channel, and decision records. It also includes installation and update components and synthetic stand and boundary tests.

The installer supports reusing a compatible existing executor account on Apple silicon. Follow the local transition and preserve the existing developer SSH key. Installation, reboot checks, and authenticated Codex acceptance on the owner's Mac remain to be completed. Financial synchronization, transaction accounting, scheduled collection, and the legacy dashboard are not provided by the trusted application. Legacy source remains available for reference.
