# Foliome 1.0.0

This first local candidate includes a trusted kernel for preparation sessions and controlled page reads, filtered snapshots, an owner interface, an executor channel, and decision records. It also includes installation and update components and synthetic stand and boundary tests.

The complete installer and verified update path have not yet been demonstrated on a separate authorized macOS installation. A real remote Codex login remains to be checked. Financial synchronization, transaction accounting, scheduled collection, and the legacy dashboard are not provided by the trusted application. Legacy source remains available for reference.
